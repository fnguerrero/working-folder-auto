    Cómo conseguir el plan
    
    
      
      
    1. SSMS: antes de ejecutar, Query → Include Actual Execution Plan (Ctrl+M). En la pestaña «Execution plan», clic derecho → Save Execution Plan As… y guardalo como .sqlplan. O clic derecho → Show Execution Plan XML y copiás todo.
      2. 
      
    2. Azure Data Studio: botón «Enable Actual Plan» (Ctrl+M) y después guardar el plan desde la barra del resultado.
      3. 
      
    3. Desde código o sqlcmd: SET STATISTICS XML ON; antes de la consulta: el plan vuelve como un resultado más, en una columna XML. Con SET SHOWPLAN_XML ON obtenés el estimado sin ejecutar (tiene que ir solo en su batch).
      4. 
      
    4. Lo que ya corrió: Query Store (sys.query_store_plan.query_plan) o la caché (sys.dm_exec_query_plan con el plan_handle de sys.dm_exec_query_stats). Son planes estimados: sin filas reales.
      5. 
    
    
    
    El plan real (actual) trae filas, lecturas y tiempos de verdad; el estimado solo lo que el optimizador creía. Para diagnosticar, siempre el real.
    

    
    Cómo leer un plan
    
    
      
      
    • Los datos fluyen de las hojas a la raíz. Acá el árbol está al revés que en SSMS: la raíz (lo que devuelve filas al cliente) arriba, y cada operador abajo de quien lo consume. En SSMS se lee de derecha a izquierda.
      • 
      
    • El porcentaje de costo es una estimación, no tiempo medido. Si las filas estimadas y las reales difieren mucho, los porcentajes mienten: miralo como una pista, no como un veredicto. Las lecturas y los tiempos por operador sí son reales.
      • 
      
    • Estimado vs. real es lo más importante. Cuando el optimizador espera 6 filas y llegan 100.000, todas sus decisiones (join, memoria, orden) se tomaron para un mundo que no existe.
      • 
      
    • Un seek no siempre es bueno y un scan no siempre es malo. Un scan de una tabla de 200 filas no importa; un seek que se ejecuta 100.000 veces, sí.
      • 
      
    • Grosor de las flechas en SSMS = filas. Acá, mirá la columna de filas reales y las ejecuciones.
